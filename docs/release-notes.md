## 云笺 1.1.2

**改名：截图待办 → 云笺，开发者 XIN。这次把界面左上角的 logo 也换了。**

### 数据不会动（重要）

这个版本采用**保守方案**：改名只影响界面，**数据目录仍然是 `%APPDATA%\截图待办`**。

从 1.0.x 直接升级过来，待办、分区记录、收纳的文件全部原地不动，不需要迁移。

万一你装过 1.1.0（那个版本会迁移数据），这次启动会把数据**搬回** `%APPDATA%\截图待办`。

### ⚠️ 装之前先卸载旧版

改名后注册表键不同，安装程序找不到旧版自动卸载：

```
设置 → 应用 → 截图待办 → 卸载
或 D:\Programs\截图待办\Uninstall.exe
```

### 安装前必看

**1. 微信收到的安装包如果变成 `YunJian-Setup.exe.1`**

后缀就不是 exe 了，双击会弹「用什么打开」。
→ 重命名，把结尾的 `.1` 删掉。

**2. 安装路径 `D:\Programs\云笺`**

没有 D 盘会自动装到用户目录。

**3. 数据在 `%APPDATA%\截图待办`**

不会随程序升级或卸载被删。

### 图标与 logo

用的是那张蓝发角色飘在云上的插画：

- 应用图标（任务栏 / 桌面 / 开始菜单）：16 到 256 全尺寸，小尺寸单独锐化
- 托盘图标：20×20
- **主窗口左上角 logo**：这次补上了，之前漏了

裁图是按蓝色头发像素自动定位中心的，不是手估坐标。

### 桌面分区

按「分区」开关进入：

- **拖文件进面板** → 文件搬进收纳目录，桌面图标消失
- **拖文件出窗口** → 自动放回桌面
- **面板之间互拖** → 改分区归属
- **支持文件夹** → 整个文件夹一起搬

关闭分区开关，里面的文件会全部放回原位。

### 分区自定义

- 拖动标题栏移动、拖边缘改大小
- **双击分区名改名**
- 右上角锁图标：锁定后位置和大小都不变
- `⋯` 里可改颜色（底色跟着变）、背景不透明度（0–100%）、新建/删除分区
- 宫格 / 列表视图每个分区独立记忆

### 其他

- 同名文件下次自动归到同一个分区
- 收纳目录里生成 `归档目录.json`，记录每个文件归到哪
- 图片预览独立窗口，可自由调整大小并记忆
- 提醒支持「每天」或「每周指定星期」
- 更新下载走国内加速镜像
