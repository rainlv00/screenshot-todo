## 云笺 1.2.0

**加了两个新东西：手动记待办、重复任务。顺手修了一批分区的问题。**

### 新增：手动记待办（不用截图）

列表顶部多了一行输入框：

```
[ 添加待办，回车创建        ] [ 重复 ] [ 添加 ]
```

- 打字回车就建好，**不用截图、不用复制**
- 没有图片的任务用一块**占位图块**（显示标题第一个字），版式和带图任务一致
- 后来想加图？**点占位块就能选一张**，图片直接存进数据目录

### 新增：重复任务

任务可以设成 **每天 / 每周 / 每月**：

- **每周可多选**（比如每周一、周四）
- **每月可多选**（比如每月 5 号、31 号；小月自动按月末算）
- 做完点一下 → 进「已完成」，**第二天自动回到待办**
- 每次完成都留一条记录，列表右侧直接显示 `已完成 12 次`
- **拖过期了不会自己跳过**，会红字标 `逾期 3 天`，该做还得做

设置入口：任务右侧那个循环箭头图标。新建时也能在输入框旁边直接选。

### 修了什么

- **拖文件进新建的分区，结果跑到「其他」** —— 拖放时没把落点告诉后端，只能靠文件名猜。现在拖到哪个面板就进哪个分区
- **分区里图标大小忽大忽小** —— 列表视图里真实图标是 34px、字母占位是 26px，混在一起看着乱。统一成 34px
- **分区框下面一大片空白，文件不往下排** —— 内容区被硬编码封顶 240px，面板拖高了也不填满。现在铺满整个面板，超出才滚动
- **标题被截断看不全** —— 鼠标悬停在缩略图或标题上，会浮出完整标题
- **滚动条太丑** —— 换成 4px 的透明细滑块，平时几乎看不见，鼠标移上去才显形

### 数据不会丢

- 待办、分区、收纳记录，位置和格式都没动
- 收纳文件仍在 `D:\收纳-YUNJIAN`
- 待办数据仍在 `%APPDATA%\截图待办`
- 升级、卸载都不会碰这两处

### 安装前必看

**1. 微信收到的安装包如果变成 `YunJian-Setup.exe.1`**

后缀就不是 exe 了，双击会弹「用什么打开」。
→ 重命名，把结尾的 `.1` 删掉。

**2. 安装路径 `D:\Programs\云笺`**

没有 D 盘会自动装到用户目录。

### 桌面分区怎么用

按「分区」开关进入：

- **拖文件/文件夹进面板** → 搬进收纳目录（拖到哪个面板就进哪个分区）
- **拖出窗口** → 自动放回桌面
- **面板之间互拖** → 改分区归属
- **双击分区名改名**，`⋯` 里改颜色、不透明度、新建/删除分区
- 关闭分区开关，里面的东西全部放回原位

### 其他
