## 云笺 1.1.5

**修一个 1.1.4 引入的毛病：文件夹拖不进分区了。**

### 为什么会坏

1.1.4 把收纳目录从 C 盘挪到了 `D:\收纳-YUNJIAN`。桌面在 C 盘，于是「把文件搬进收纳」这件事从「同盘改名」变成了「跨盘复制」。

代码里原来写的跨盘备份是 `copyFileSync` —— **它只能复制单个文件，碰到文件夹直接报错**。错误被吞掉了，所以表现出来就是「拖进去没反应，也不报错」。

### 修法

跨盘改走 `fs.cpSync`（递归复制文件夹）再删源，同时把「文件被占用、权限不足」也纳入复制回退，不再静默失败。

拖进去、拖出来、关闭分区放回、删分区还原——这四条路都走同一个函数，一起修好了。

**实测**：在 C 盘建了个带子目录的文件夹，通过程序收录 → 成功搬到 `D:\收纳-YUNJIAN\其他\`，源目录已清除，嵌套文件和内容完整。

### 1.1.4 的其他改动（没变）

- 收纳目录固定在 `D:\收纳-YUNJIAN`，跟安装目录分开，卸载升级都不碰
- 主窗口记住位置和大小，关掉重开回原位
- 分区面板位置存数据库，清缓存不丢

### 安装前必看

**1. 微信收到的安装包如果变成 `YunJian-Setup.exe.1`**

后缀就不是 exe 了，双击会弹「用什么打开」。
→ 重命名，把结尾的 `.1` 删掉。

**2. 安装路径 `D:\Programs\云笺`**

没有 D 盘会自动装到用户目录。

**3. 数据位置**

- 待办、分区记录：`%APPDATA%\截图待办`
- 收纳的文件和文件夹：`D:\收纳-YUNJIAN`

两处都不会随程序升级或卸载被删。

### 桌面分区怎么用

按「分区」开关进入：

- **拖文件/文件夹进面板** → 搬进收纳目录，桌面图标消失
- **拖出窗口** → 自动放回桌面
- **面板之间互拖** → 改分区归属
- **双击分区名改名**，`⋯` 里改颜色、不透明度、新建/删除分区
- 关闭分区开关，里面的东西全部放回原位
