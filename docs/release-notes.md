## 云笺 1.1.4

**两个你一直想要的东西：收纳文件不再占 C 盘，窗口位置记不住了。**

### 收纳目录搬到 `D:\收纳-YUNJIAN`

以前的收纳文件藏在 `C:\Users\你\AppData\Roaming\截图待办\收纳`，C 盘越用越满，还找不到。

现在固定放 **`D:\收纳-YUNJIAN`**：

- 跟安装目录完全分开，**卸载、升级、删程序目录都不会碰它**
- 第一次启动会自动把老数据**复制**过来（是复制，不是移动，旧目录留着当备份，确认没问题你自己删）
- 没有 D 盘的话，退到「安装目录\收纳-YUNJIAN」；再不行才回用户目录

### 窗口位置记住了

- **主窗口**：拖到哪、拉多大，关掉重开就回原位
- **分区面板**：每个分区各自的坐标也记住了，重开直接摆在你上次放的地方

以前主窗口根本没存位置，每次都是系统居中——这是漏写的，不是坏了。

### 分区面板位置改存数据库

原来存在浏览器本地缓存里，清缓存或某些更新会丢。现在跟你的待办数据存在一起，启动时以数据库为准。

### 数据不会丢

- 待办、分区、收纳记录，位置和格式都没动
- 老的收纳目录原样保留，你确认新位置没问题再自行删除

### 安装前必看

**1. 微信收到的安装包如果变成 `YunJian-Setup.exe.1`**

后缀就不是 exe 了，双击会弹「用什么打开」。
→ 重命名，把结尾的 `.1` 删掉。

**2. 安装路径 `D:\Programs\云笺`**

没有 D 盘会自动装到用户目录。

**3. 待办数据在 `%APPDATA%\截图待办`，收纳文件在 `D:\收纳-YUNJIAN`**

两处都不会随程序升级或卸载被删。

### 桌面分区怎么用

按「分区」开关进入：

- **拖文件进面板** → 文件搬进收纳目录，桌面图标消失
- **拖文件出窗口** → 自动放回桌面
- **面板之间互拖** → 改分区归属
- **支持文件夹** → 整个文件夹一起搬

关闭分区开关，里面的文件会全部放回原位。

### 分区自定义

- 拖动标题栏移动、拖边缘改大小
- **双击分区名改名**
- 右上角锁图标：锁定后位置和大小都不变
- `⋯` 里可改颜色、背景不透明度（0–100%）、新建/删除分区
- 宫格 / 列表视图每个分区独立记忆

### 其他

- 同名文件下次自动归到同一个分区
- 收纳目录里生成 `归档目录.json`，记录每个文件归到哪
- 图片预览独立窗口，可自由调整大小并记忆
- 提醒支持「每天」或「每周指定星期」
- 更新下载走国内加速镜像
