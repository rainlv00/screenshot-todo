========================================
  云笺 v1.0.1  使用说明
  Windows 10 / 11 x64 · 免安装 · 不联网
========================================

【怎么打开】
双击本目录下的「云笺.exe」即可，不需要安装。
建议右键它 → 发送到 → 桌面快捷方式。
第一次运行会在开始菜单建一个「云笺」快捷方式，别删——
系统通知要靠它才能弹出来。

--------------------------------------------------
一、收录一张待办（核心用法）
--------------------------------------------------
1. 微信按 Alt+A 截图
2. 点截图工具栏上的 √（复制到剪贴板）
3. 0.9 秒内卡片自动出现在窗口里，右下角弹「已收入待办」，5 秒内可撤销

★ 必须点 √，不能点「另存为」。
  只有进了剪贴板的图才会被收录。

也可以在窗口里按「收录剪贴板」按钮，或按快捷键 Ctrl+Alt+V。

--------------------------------------------------
二、做完了 / 做错了
--------------------------------------------------
· 点卡片左边的方框      → 掉进「已完成」
· 在「已完成」再点一次  → 回到待办，并记一次「拿回过」
· 悬停卡片点右侧垃圾桶  → 删除，6 秒内可撤销

窗口里没有别的删除入口，删除是唯一不可逆操作，
所以给了 6 秒后悔时间，别急着关。

--------------------------------------------------
三、每天都在拖怎么办
--------------------------------------------------
每张卡片标着「今天 / 拖了 3 天 / 拖了 2 周」，颜色随天数变：
  0-2 天 灰   3-6 天 橙   7 天以上 红
「积压」区把放得最久的排在最上面——这是故意的，让你正视它。

--------------------------------------------------
四、截图不是待办怎么办（重要）
--------------------------------------------------
做教程、发图给同事时，连续截图会全跑进待办。
别一张张删，直接暂停收录：

· 窗口底部有个滑动开关：绿色「收录中」= 正在收，红色「已停止」= 不收
  开关右边就是它的快捷键，点一下或按快捷键都能切
· 托盘图标右键 → 暂停收录 → 15 分钟 / 1 小时 / 到明早
· 临时暂停时，窗口顶部还有一条橙色倒计时，点一下立刻恢复

--------------------------------------------------
五、外观
--------------------------------------------------
标题栏（左上角是当天日期）右侧几个按钮：

[半圆图标] 不透明度 10%-100% + 底色六选一
           白 / 灰 / 黑 / 蓝 / 绿 / 黄
           调低能看到桌面，文字不会跟着变淡
           选深色底会自动换成浅色字

[图片图标] 换背景：可以裁剪，可选铺法
           「完整（留底色）」图片按比例完整显示
           「铺满（裁边）」拉满面板裁掉超出部分
           背景太花就调高遮罩

[锁]       锁定面板：锁上后拖不动、关不掉，防止误触
           解锁方法：托盘右键 → 解锁面板

窗口可以随意拉伸，最小 320×360。

--------------------------------------------------
六、关于「挡不挡软件」
--------------------------------------------------
「始终置顶」默认是关的。
关着 = 普通窗口，别的软件会正常盖住它，不挡你干活。
需要一直看着就打开置顶（设置里或托盘右键）。

如果你用 Wallpaper Engine 之类的动态壁纸：
本程序是普通窗口，不会影响壁纸播放；
壁纸软件若设置了"有窗口时暂停"，那是它自己的规则，
本程序不是全屏/最大化窗口，一般不会触发。

--------------------------------------------------
七、列表 / 宫格
--------------------------------------------------
标签行右侧的小方块按钮切换。
宫格适合「图很多，先扫一眼哪个眼熟」，列表适合精确管理。

--------------------------------------------------
八、每日提醒
--------------------------------------------------
默认每天 08:30 弹一条系统通知：
「7 条待处理，最早一条压了 4 天」
没有待办时不打扰。时间可在设置里改。

收不到通知的排查顺序：
1. 开始菜单里还有「云笺」这个快捷方式吗？删了通知就弹不出来
2. Windows 设置 → 系统 → 通知 → 找到「云笺」，确认没被关掉
3. 开了「专注助手 / 勿扰模式」的话，通知会被拦

--------------------------------------------------
九、数据在哪 / 怎么备份（重点）
--------------------------------------------------
数据不在 exe 目录里，在用户目录：

  %APPDATA%\云笺\data\
    tasks.db        任务记录（SQLite）
    images\         原图（压缩后）
    thumbs\         缩略图
    background.jpg  你设的背景图

为什么要这样：以前数据放在 exe 旁边，结果每次换新版本、
重新解压覆盖，data 目录就被新包盖掉了，截图全没了。
现在和 exe 完全分开 —— 换版本、删了 exe 重装，数据都还在。

老版本的数据会在第一次运行新版本时自动搬过来，
旧的 data 目录原样保留当备份，不会删。

备份 = 复制 %APPDATA%\云笺\data 整个文件夹
换电脑 = 把它放到新机器同一位置，直接接着用

100 条待办大约占 30MB。

--------------------------------------------------
九点五、双击没反应 / 弹出"选择打开方式"怎么办
--------------------------------------------------
这种情况通常是解压后点错了文件，或者系统的 exe 关联被改坏了。

【先确认点的是哪个文件】
  正确的文件：云笺.exe（图标是一只狗的头像）
  点这些没用：使用说明.txt、resources 文件夹里的任何文件

【如果双击 云笺.exe 弹出"选择打开方式"】
  说明 .exe 关联被改坏了（常见于误把 txt/lnk 的关联改成了 WPS 等）。
  修复：设置 → 应用 → 默认应用 → 按文件类型指定默认应用
       找到 .exe → 改成"应用程序"或"Windows 命令处理程序"
  更省事的办法：直接重装一遍软件，或者换个文件夹重新解压。

【重要：以后发版一律用安装包】
  安装包 ScreenshotTodo-Setup-x.x.x.exe 双击就装，不用解压、
  不用找 exe，装完桌面自动有图标。zip 包只留给自己备份用。

--------------------------------------------------
十、快捷键
--------------------------------------------------
默认：
  Ctrl+Alt+V   把剪贴板里最新的图收录进待办
  Ctrl+Alt+J   开启 / 停止收录（和底部那个滑动开关是一回事）

两个都能在「设置 → 快捷键」里自己录，
规则：必须有 Ctrl/Alt/Shift/Win 之一，总共 2-3 个键。
如果设置里显示"未生效：已被其他程序占用"，换一个组合就行。

--------------------------------------------------
十一、退出
--------------------------------------------------
点窗口的 × 只是收进托盘，程序还在后台跑
（这样每日提醒和自动收录才有效）。

真正退出：托盘图标右键 → 退出云笺。

--------------------------------------------------
十二、常见问题
--------------------------------------------------
Q: 截了图没反应？
A: 八成点的是「另存为」而不是 √。再看设置里
   「自动收录剪贴板图片」是否被关掉。

Q: 同一张图重复出现？
A: 不会。程序按图片内容去重，同一张图只收一次。

Q: 换背景没反应？
A: 选图对话框必须挂在主窗口上才不会被盖住（已修）。
   如果仍然打不开，托盘右键 →「打开数据目录」看
   data\background.jpg 有没有生成。

Q: 程序日志在哪？
A: 出问题会写 crash.log 在 exe 同目录，反馈时带上它。
